# American Tourist Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze American tourist travel patterns, spending behavior, destinations, accommodation preferences, transportation modes, and feedback.

The dashboard provides insights into 15,000 tourist records and helps understand travel trends and revenue performance.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

## Key KPIs

- Total Tourists: 15K
- Total Revenue: $78.84M
- Average Trip Cost: $5.26K
- Average Feedback Score: 3.20

## Dashboard Analysis

### Tourist Demographics

- Travel purpose
- Top destination cities

### Financial Analysis
- Total revenue
- Trip cost by transport mode
- Top spending cities
- Revenue by travel agency

### Feedback Analysis
- Average feedback score by accommodation type
- Hotel-wise tourist count and feedback score

## Key Insights

- The dataset contains 15,000 tourists.
- Total revenue generated is $78.84M.
- Average trip cost is $5.26K.
- Average feedback score is 3.20.
- The dashboard compares tourist activity across major destination cities.
- Expedia records the highest revenue among the displayed travel agencies at $16.23M.
- Cruise has the highest trip cost among the displayed transport modes at $16.21M.
